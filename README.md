# FitLog — Workout Library

FitLog is a modern workout library web application that helps users explore exercises, create a daily workout plan, save workouts for later, and track their completed exercises. The application provides a simple dark-themed interface with responsive design for different screen sizes.

## Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- REST API
- Local Storage

## Key Features

1. **Workout Library**
   - Browse workout exercises with images, muscle groups, equipment, duration, calories, and ratings.

2. **Workout Details**
   - View detailed information about each workout, including specifications and step-by-step instructions.

3. **Today's Workout Plan**
   - Add up to five workouts to today's plan and track the total exercises, minutes, and calories.

4. **Save Workouts for Later**
   - Save favorite workouts and access them anytime from the Saved tab.

5. **Workout Tracking & Sorting**
   - Mark workouts as completed, remove them from the plan, and sort workouts by duration, calories, or rating.
